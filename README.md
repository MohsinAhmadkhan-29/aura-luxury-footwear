# 👟 Aura Footwear — Premium E-Commerce Experience

A high-converting, luxury e-commerce web application built with modern frontend tools focusing on performance, smooth animations, and interactive shopping workflows.

🌐 **Live Demo:** https://aura-luxury-footwear.vercel.app/

## ✨ Key Features
- **Dynamic Promo Bar & Popup:** Real-time countdown timer with discount activation.
- **Interactive Product Catalog:** Micro-interactions, hover effects, and full product view.
- **Cart & Checkout Workflow:** Slide-out drawer, live discount code application (`STEP30`), and calculated price summary.
- **Fully Responsive:** Optimized for mobile, tablet, and desktop views.

## 🛠 Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide-React
- **Deployment:** Vercel

## 🚀 Quick Start
```bash
# Clone the repository
git clone [https://github.com/MohsinAhmadkhan-29/aura-luxury-footwear.git](https://github.com/MohsinAhmadkhan-29/aura-luxury-footwear.git)

# Install dependencies
npm install

npm run dev
